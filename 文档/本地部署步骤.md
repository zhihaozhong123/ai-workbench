## 使用本地http后端发布版本

### 1. tauri.conf.json 配置

- beforeBuildCommand 要使用正确的路径

- security 要使用正确的 csp

- 使用的是 http，所以不用配置 updater，具体不同点可与 `使用 https 后端发布版本` 对比

```json

{
  "$schema": "https://schema.tauri.app/config/2",
  "productName": "小书童",
  "version": "2.0.0",
  "identifier": "com.xiaoshutong.app",
  "build": {
    "beforeBuildCommand": "cd ../frontend && npm install && npm run build",
    "frontendDist": "../frontend/dist"
  },
  "app": {
    "windows": [
      {
        "label": "main",
        "title": "小书童",
        "width": 1100,
        "height": 800,
        "minWidth": 800,
        "minHeight": 600,
        "resizable": true,
        "fullscreen": false
      }
    ],
    "security": {
      "csp": "default-src 'self'; connect-src 'self' https: wss: http://127.0.0.1:* ws://127.0.0.1:* http://localhost:* ws://localhost:*; img-src 'self' data: blob:; style-src 'self' 'unsafe-inline'; script-src 'self'; font-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'"
    }
  },
  "bundle": {
    "active": true,
    "targets": ["app"],
    "icon": ["icons/icon.png"],
    "macOS": {
      "signingIdentity": null,
      "entitlements": "Entitlements.plist"
    }
  }
}

```

### 2. src-tauri/capabilities/default.json 配置

```json

{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "default",
  "description": "小书童默认权限：前端通过原生 fetch / WebSocket 直连本机后端，无需额外 Tauri 插件权限。",
  "windows": ["main"],
  "permissions": [
    "core:default",
    "dialog:default"
  ]
}

```

### 3. 确认 docker 在运行

> docker ps 

### 4. 修改 scripts/publish_update.sh 文件

- 将 scripts/publish_update.sh 文件的这两处配置改为backend的服务器地址，比如backend的端口号是8000，我的本机ip是192.168.0.105，有域名后改为域名。

```json

"platforms": { "darwin-${ARCH}": { "signature": "${SIG_BASE64}", "url": "http://192.168.0.105:8000/download/${DMG_FILENAME}" } }

...
...
...

echo "==> 发布步骤：" echo " 1. 上传 ${DMG_PATH} 到你的服务器下载目录" echo " 2. 上传 ${MANIFEST_FILE} 到更新端点 URL" echo " 3. tauri.conf.json 中 plugins.updater.endpoints 应指向:" echo " http://192.168.0.105:8000/update/darwin/${ARCH}/{{current_version}}"

```

### 5. 发版本

#### 1. 更新版本号

- 发版本之前更新这里的版本号 2.0.0

``` tauri.conf.json

{
  "$schema": "https://schema.tauri.app/config/2",
  "productName": "小书童",
  "version": "2.0.0", // 改这里
  "identifier": "com.xiaoshutong.app",
}

```

#### 2. 发版本

```js

cd /Users/zhongzhihao/python_project/xiaoshutong

# 执行构建：启动后端 + 构建 .app + 封装 DMG
bash up_build.sh

```
>  脚本会交互询问：

> 选 0（不清数据）→ 保留数据库/知识库/对话记录，仅重启

> 选 1（清数据）→ 清空一切后重启（相当于全新安装）

> up_build.sh 自动做了：

> 启动 docker compose（backend ×2 + nginx + db + redis + chroma + prometheus + 备份服务）

> 重新构建 backend 和 nginx 镜像（含最新代码）

> 自检 /readyz 和登录接口可达性

> cargo tauri build → 构建 小书童.app

> bash scripts/create_dmg.sh → 封装 小书童_2.0.0.dmg

产物位置：

```code
src-tauri/target/release/bundle/macos/
├── 小书童.app          # 应用
└── 小书童_2.0.0.dmg    # 分发镜像
```
