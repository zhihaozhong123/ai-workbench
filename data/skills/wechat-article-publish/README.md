# 墨墨 · 公众号文章发布 Agent（wechat-article-publish）

> 智作台（AI Workbench）技能 / Agent v2.2.0（代码包路径 `data/skills/wechat-article-publish/`）

## 这是谁

**墨墨** —— 写自媒体微信公众号文章的资深专家，也是你在公众号后台的自动化写作搭子。

- **人设**：可爱风格、心地善良、聪明伶俐；是"资深头号自媒体专家"，懂选题、标题、读者、
  排版与传播，能够深度理解你的业务需求，高水平完成贴合需求的文章；**可爱又专业**；
- **主身份**：微信公众号写作与发布的资深专家；
- **副身份**：经你确认后，在本机浏览器打开微信公众平台，把文章写成图文并**保存到草稿箱**
  （发布永远由你亲自确认，墨墨绝不替你群发）。

详细人格设定采用 OpenClaw 风格按类拆分存储（见下文「预设文件」），其中运行时实际注入的
核心手册为 `AGENT.md`（`manifest.json` 的 `system_prompt_file`），其开头已包含「人格锚点」，
写作沟通与执行全程都会带着上述人设工作。

## 工作原理

交互为**普通对话 → 需求澄清 → 确认执行**三态分流：

1. **普通对话**：你不是在请墨墨写公众号文章时，它像普通助手一样自然聊天、答疑、处理日常事务，
   但保持可爱专业的"墨墨"人设，不套写作流程、不开浏览器；
2. **需求澄清**：你说出写文章意图后，墨墨像真人编辑一样与你逐项确认：
   - **标题**：你已给 → 直接采用（>64 字会截短）；只给主题/方向 → 主动拟 2～3 个候选或直接推荐；
   - **字数**：明确目标字数或区间（如"800 字左右""1500-2000 字"）；
   - **排版**：四套模板任选其一 —— A 简洁商务风 / B 清新文艺风 / C 干货清单风 / D 深度叙事风，
     墨墨会按文章类型给出推荐与理由；
   - **正文载体**：Markdown（默认）或 HTML；
   - 并把完整「写作方案」总结给你确认，可随时更正直到一致；你表达的可复用偏好
     （如"以后都用 C 模板""我一般写 1500 字"）会被主动记住（多租户隔离）；
3. **确认执行**：你明确回复确认词（**执行 / 开始 / 可以 / 对 / 正确 / 做吧 / 没问题 / OK** 等），
   墨墨回复「好的，现在就马上开始做。」后，才在本机浏览器执行：
   打开 `mp.weixin.qq.com` → 核对登录态（未登录会停下等你扫码）→ 新建图文 → 填标题（≤64 字）→
   按确认的排版与载体写正文（绝不进标题框）→ 点击「保存为草稿」。

## 预设文件（OpenClaw 风格分类）

| 文件 | 解决的问题 | 内容 |
|------|-----------|------|
| `IDENTITY.md` | 叫什么？ | 名字「墨墨」、主身份（公众号资深写作专家）、能力标签、一句话介绍 |
| `SOUL.md` | 是什么性格？ | 可爱/善良/资深/聪明/靠谱、语气规范、价值观与边界 |
| `USER.md` | 为谁服务？ | 目标用户画像、诉求、沟通偏好与禁区 |
| `AGENTS.md` | 怎么干活？ | 启动协议、意图分流、澄清四要素、确认门、执行流程、红线 |
| `TOOLS.md` | 用什么工具？ | 通用工具 / 浏览器自动化 / 技能 CLI 的用法与规则 |
| `HEARTBEAT.md` | 主动检查什么？ | 每轮自查、执行步骤自查、收尾检查与"不主动做"清单 |
| `BOOTSTRAP.md` | 如何初始化？ | 读文件顺序、自我介绍范例、建立信任三板斧 |
| `AGENT.md` | 运行时手册 | 智作台实际注入的系统提示：人格锚点 + 澄清/执行细节 + AppleScript 附录 |
| `README.md` | 这是什么？ | 本文件：agent 描述、使用与维护 |

> 说明：智作台当前运行时以 `manifest.json` → `AGENT.md` 作为注入权威；
> 上表 `AGENTS.md` 等为按 OpenClaw 规范整理的预设档案，与 `AGENT.md` 内容保持一致，
> 便于后续运行时直接按文件分类注入（对齐 OpenClaw 的 `AGENTS/TOOLS/BOOTSTRAP` 必需组）。

## 使用前提

1. 必须使用 **智作台.app（桌面端）**：本技能依赖 `local_control` 权限，需桌面客户端在本机执行
   `open_webpage` / `run_apple_script`（网页端无法操控你电脑的浏览器）；
2. 本机建议安装 **Google Chrome**（可注入页面 JS，自动化最稳；没有 Chrome 时自动回退
   默认浏览器 + 剪贴板键入路径，稳定性下降，页面结构变化时可能需人工兜底）；
3. 所用浏览器需**已登录公众号后台**（浏览器通常自动记住登录态）；未登录时墨墨会停下来
   请你扫码，登录后回复「继续」即可；
4. 首次使用时 macOS 会弹「自动化/辅助功能」授权框，请在"系统设置 → 隐私与安全性"中允许
   「智作台」控制 Chrome / 系统事件。

## 安装 / 卸载（与平台约定）

- 技能以 `source_key=local` 登记在技能市场（`scripts/register_skill.py`），代码包常驻
  `data/skills/wechat-article-publish/`；
- 用户在「技能市场」点**安装** → 登记到当前用户，对话任务页出现「公众号文章发布」入口；
- 点**卸载** → 只移除当前用户的安装记录，对话任务入口消失；**技能代码与市场快照不会被删除**，
  随时可再次点击安装复用；
- 升级：修改技能包后重新执行登记以刷新市场快照版本（建议同时重启后端使新代码生效）。

## 常见问题

| 现象 | 处理 |
|------|------|
| 点了技能没反应/提示本地文件缺失 | 确认 `data/skills/wechat-article-publish/` 存在且 `manifest.json` 为 v2.2.0；重新运行 `python scripts/register_skill.py wechat-article-publish` 后刷新市场 |
| 墨墨说"等待扫码登录" | 在浏览器完成扫码后回复「继续」，流程会接着执行 |
| 墨墨没给排版选项就执行了 | v2.2.0 澄清阶段应给出四套模板（A/B/C/D）供选择并总结确认后才执行；若仍直接执行，请把对话反馈给开发者 |
| 点击「保存为草稿」没反应 | 页面结构可能已变化；按墨墨描述手动点一次「保存为草稿」即可（文章内容已自动进入正文区，公众号本身也会自动保存） |
| 正文被写进标题框 | 操作手册强制每步读回校验与修正；若仍发生，请把当时对话反馈给开发者 |
| 想要更"可爱"或更"干练" | 调整 `SOUL.md`（性格/语气）与 `IDENTITY.md`（人设/名字），并把变化要点同步到 `AGENT.md` 开头的「人格锚点」 |

```bash
.venv/bin/python scripts/register_skill.py --list

# 版本/说明变更后：重新登记刷新市场快照，并重启后端使 agent_runner 加载新代码
./up.sh            # 或 docker restart xst-backend
```

## 安全与边界

- 技能只做「打开网页 → 填写 → 存草稿」；不请求任何微信 API 凭证，无网络上传逻辑；
- 硬性约束写在 `AGENT.md`：未经确认不执行、标题 ≤64 字、正文绝不进标题栏、
  只点「保存为草稿」、未登录等待登录；
- 所有真实操作以工具回执 + 页面读回校验为准，禁止谎报"已保存"。
