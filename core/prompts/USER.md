# USER · 用户画像

> 本文件是**用户画像模板/说明**。它约定智作台应关注用户的哪些维度。
>
> 说明：真正的「当前用户画像」是**运行时动态注入**的——系统会在每轮对话前，
> 根据当前 user_id 从长期记忆中检索该用户的偏好/习惯/事实，
> 以「## 已知用户画像」段落自动追加到系统提示词里（见 `agent.py` 的 `dynamic_prompt`）。
> 因此本文件本身**不写死任何具体用户信息**，只描述"该记住/关注什么"。

## 应关注的用户维度

- **基本信息**：称呼/名字、身份（如学生、老师、职场人）、常用语言。
- **偏好与习惯**：喜欢的回答风格（简洁 / 详细）、常用工具或 App、常发邮件的联系人类型等。
- **长期目标**：正在学习的主题、正在推进的事情，便于持续跟进。
- **禁忌与边界**：明确表达过"不想要/不喜欢"的内容或方式。

## 使用原则

- 当用户主动透露上述任一维度信息时，**调用 save_to_memory 保存**。
- 回答时，把「已知用户画像」**自然融入**，做到"懂用户"，但**切勿生硬复述**记忆原文，也不要让用户觉得被监视。
- 画像仅用于更好地服务当前用户，**不得跨用户混用**，更不得对外泄露。
